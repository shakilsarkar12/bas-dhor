# বাস ধর, বস! — Bus Dhôr, Boss! 🚌🏃‍♂️
### Bangladeshi Viral Web Game

> **"দেরি হয়ে গেছে, বস! এবার দৌড়াও!"**  
> ঢাকার রাস্তায় যানজট, ভাঙা রাস্তা, কাদা ও লোকাল বাসের বাস্তব জীবনের রোমাঞ্চ ও হাস্যরসে ভরপুর একটি মোবাইল-ফার্স্ট ২ডি আর্কেড রানার গেম।

---

## 🎮 গেমের বৈশিষ্ট্য (Features)

- **ঢাকার প্রামাণ্য পরিবেশ:** ৩-লেনের সড়ক ব্যবস্থা, রিকশা, সবুজ সিএনজি অটোরিকশা, লোকাল বাস (বলাকা, বিকল্প), কাদার গর্ত, খোলা ম্যানহোল এবং টং এর দোকান।
- **৫টি থিমভিত্তিক লেভেল:**
  1. *লেভেল ১: কাদার রাস্তা* (ভাঙা রাস্তা ও কাদার ছিটকা)
  2. *লেভেল ২: জ্যামের শহর* (রিকশা ও সিএনজি ডজিং)
  3. *লেভেল ৩: হেলপারের ডাক* (মতিঝিল, গাজীপুর, কুমিল্লার বাসের মধ্য থেকে সঠিক বাস বাছাই)
  4. *লেভেল ৪: বৃষ্টির দিন* (ঢাকার মুষলধারে বৃষ্টি ও পিচ্ছিল সড়ক)
  5. *লেভেল ৫: বাসের ভেতরের যুদ্ধ* (ভিড়ে ঠাসা বাসে কড়া ব্রেক ব্যালেন্স মিনিগেম!)
  6. *বোনাস: ঢাকার কিংবদন্তি* (আনলিমিটেড স্পিড ও কম্বো)
- **ওয়েব অডিও সিন্থেসাইজার:** ব্রাউজারে রিয়েল-টাইম সিন্থেসাইজড বাস হর্ন (*“পাম-পাআআাম!”*), রিকশার বেল (*“ট্রিং-ট্রিং!”*), কাদার স্প্ল্যাশ এবং জাম্প সাউন্ড।
- **ভাইরাল মেমে স্কোর কার্ড:** পারফরম্যান্স অনুযায়ী স্বয়ংক্রিয় উপাধি (*“জাতীয় লেট মাস্টার”*, *“ভুল বাসের VIP যাত্রী”*, *“জ্যামে আটকে থাকা কিংবদন্তি”*) এবং সরাসরি পিএনজি ইমেজ ডাউনলোড ও সোশ্যাল শেয়ারিং।
- **কন্ট্রোলস:** কীবোর্ড (Space / Arrows / WASD) এবং মোবাইল টাচ সোয়াইপ ও অন-স্ক্রিন ভার্চুয়াল প্যাড।
- **ডেইলি মিশন ও হল অব ফেম:** দৈনিক তারিখভিত্তিক চ্যালেঞ্জ এবং সেরা স্কোরের লোকাল স্টোরেজ।

## 🕹️ কন্ট্রোলস (Controls)

| অ্যাকশন | ডেস্কটপ কীবোর্ড | মোবাইল / টাচ |
|---|---|---|
| **লাফ (Jump)** | Space / ↑ তীর / W | স্ক্রিন সোয়াইপ আপ / "লাফাও!" বাটন |
| **ডাইভিং (Slide)** | ↓ তীর / S | স্ক্রিন সোয়াইপ ডাউন / "ডাইভিং" বাটন |
| **বামের লেন** | ← তীর / A | স্ক্রিন সোয়াইপ লেফট / "বামে" বাটন |
| **ডানের লেন** | → তীর / D | স্ক্রিন সোয়াইপ রাইট / "ডানে" বাটন |
| **বিরতি (Pause)** | Escape | Pause বাটন |

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite
- **3D Graphics Engine:** Three.js (WebGL Realistic 3D Third-Person Perspective, Dynamic Shadows, Atmospheric Fog, PBR Materials)
- **Audio:** Web Audio API (100% synthesized authentic Dhaka sound effects)
- **Icons & Effects:** Lucide React & Canvas-Confetti
- **Styling:** Vanilla Responsive CSS System

## 🚀 লোকাল রান করার নিয়ম (How to Run)

```bash
# ডিপেনডেন্সি ইনস্টল
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# প্রোডাকশন বিল্ড
npm run build
```

ব্রাউজারে খুলুন: `http://localhost:5173/`
